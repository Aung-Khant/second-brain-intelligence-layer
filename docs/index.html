Second Brain Intelligence Layer
How it works Confidence Install GitHub

Automate the filing.
Not the thinking.

A Chrome extension that files what you watch into your Notion second brain — reading the facts from the page, asking a model what it means, and leaving the judgment to you.

  • Code handles facts
  • AI handles meaning
  • Humans handle intent
The pipeline

Six stages, and each one has an owner

The colours above aren't decoration. Every stage below belongs to exactly one of the three — and the boundaries are enforced in code, not by asking the model nicely.

Code

Capture

Reads YouTube's own player payload for the video ID, title, channel, and description. No scraping of rendered markup.

Code

Validate

Rejects a missing title, a non-video URL, or metadata belonging to a different video than the address bar. Bad input never reaches the model.

AI · pass 1

Understand

Summarises what the resource actually covers. Never sees your taxonomy, so it can't bend the summary toward a convenient answer.

AI · pass 2

Classify

Matches against your real Areas, Projects, and Topics, returning a confidence and a reason for each. IDs are checked against the taxonomy in code.

Human

Confirm

You keep, drop, or add. You write why you saved it — the one field neither code nor a model is allowed to fill in.

Code

Save

Writes the page through the Notion API and records what the model suggested against what you actually chose.

Selection

A suggestion you have to undo is worse than none

Confidence decides what arrives pre-selected. The thresholds live in one place on the server, so the extension can only render the decision — never reinterpret it.

≥ 0.90
Selected for you

Unmistakably, centrally about this entity. Arrives ticked.

0.70 – 0.89
Offered, not assumed

Clearly relevant and shown with its score, but you decide.

< 0.70
Discarded

Dropped server-side before it reaches you, however confident the wording sounds.

An empty result is a correct result

If nothing genuinely fits, every group comes back empty and the resource saves with no relations at all. Null beats a wrong classification.

The model cannot invent taxonomy

Classification can only return IDs that already exist in your workspace — enforced by filtering against the fetched taxonomy, not by instructing the model. New Areas, Projects, and Topics are created only when a person types a name and confirms it.

Every correction is recorded

Each suggestion is compared with your final choice and logged as accepted, rejected, or manually added. That history stays in the backend — your Notion holds clean knowledge, nothing else.

What lands in Notion

One row, seven properties

Written through the Notion API using your database's own default template — never by driving the Notion UI.

Property Source
Name Video or channel title, stripped of the tab's unread badge and “ - YouTube”
URL Canonical URL rebuilt from the verified ID, not the address bar
Type Video, or YouTube Channel
Description The model's summary — two or three sentences
Why Saved Yours. Required, and never AI-generated
Areas · Projects · Topics Relations to entities that already existed, or that you created deliberately
Getting started

Runs entirely on your machine

Your Notion key stays in the backend and never reaches the browser. The extension only ever talks to localhost.

  1. Clone and install

    git clone https://github.com/Aung-Khant/second-brain-intelligence-layer
cd second-brain-intelligence-layer
npm install

  2. Connect Notion

    Create an internal integration, share your Areas, Projects, Topics, and Resources databases with it, then put the secret and the four data source IDs in .env.

  3. Start the backend

    npm run build
npm run server

  4. Load the extension

    In chrome://extensions, enable Developer mode and load the extension/ folder unpacked. Open a YouTube video and click it.
